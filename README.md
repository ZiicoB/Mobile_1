# Mobile_1º

Homepage and contact page of a website for RPG content.

## 📚 About the Project

- **My third project.**
  
The project was an attempt to create a template for an RPG content website, initially designed for mobile devices, with responsive adaptations for PC and tablet versions later on.
In addition to the homepage, I also created the contact page, which is marked with (*) at the bottom of the page.

- **Problems encountered**
  
During the creation of the first image carousel, a bug was identified where, after the last image, the carousel continued scrolling and creating a phantom space instead of returning to the first image.

After much persistence, I managed to solve the problem.
However, a few days later, the same error occurred again.

I tried for several days to find out what the problem was this time, but I was unsuccessful and decided to finish the rest of the project, unfortunately leaving this error behind.
