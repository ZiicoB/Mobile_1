# Mundo RPG

[Português](#-português) | [English](#-english)

---

## 🇧🇷 Português

Template responsivo para um site voltado para criação de recursos de RPG (mapas, itens, criaturas e planos). Apenas a página inicial e a de contato foram feitas, além de uma pequena janela modelo para fazer login.

### Principais recursos

- **Home (`index.html`)**: barra fixa com busca por tema, carrossel infinito de mapas por categoria (Swiper 11), slider de itens e criaturas, FAQ em acordeão, alternador de planos Mensal/Anual e modal de login.
- **Contato (`contato.html`)**: formulário com validação, máscara de telefone e contador de caracteres.

### Como rodar localmente

```bash
python -m http.server 8123
```

Acesse `http://localhost:8123` no navegador.

### Tecnologias

HTML5 • CSS3 • JavaScript • Swiper 11

## 🇺🇸 English

Responsive template for a website focused on creating RPG assets (maps, items, creatures, and plans). Only the home and contact pages were built, along with a small modal window for login.

### Key features

- **Home (`index.html`)**: sticky navbar with theme search, infinite categorized map carousel (Swiper 11), items & creatures slider, FAQ accordion, Monthly/Annual plan toggle, and login modal.
- **Contact (`contato.html`)**: form with validation, phone input mask, and live character counter.

### Run locally

```bash
python -m http.server 8123
```

Open `http://localhost:8123` in your browser.

### Tech stack

HTML5 • CSS3 • JavaScript • Swiper 11
